ELEC330 Project: Biometric Turtle (“Turtle-on-Land”)

Project Repository on GitHub

Navigation Basic World for the turtle robot

Project Overview

The “Turtle-on-Land” project was part of the ELEC330 module at the University of Liverpool, aiming to design and implement a biometric-inspired mobile robot capable of autonomous navigation and object recognition within a simulated environment.
Built on the ROS2 Jazzy framework, the project integrated multiple subsystems, including SLAM, navigation, perception, and control, into a cohesive robotic system tested in Gazebo.

My Role and Contributions

Shaotong Hong was primarily responsible for the design and implementation of the SLAM subsystem, a critical component enabling the robot’s autonomous navigation.

SLAM System Development

  • Designed and deployed the SLAM subsystem for the turtle robot, ensuring real-time map generation and seamless interaction with the Nav2 navigation stack.
  • Implemented an occupancy grid map and maintained the map → odom transform, enabling dynamic localization and path planning consistency within ROS2’s TF framework.
  • Transitioned the system architecture from a 3D LiDAR-based SLAM approach (using the lidarslam package in Assignment 2) to a more efficient 2D laser-based implementation utilizing slam_toolbox in online_async mode.

3D SLAM result

2D SLAM result

  • This optimization significantly reduced computational load, achieving real-time performance on resource-limited hardware while improving odometry compatibility.

Supplementary Work

  • Developed a backup target-recognition pipeline using Gazebo’s bounding box camera plugin to support and validate the robot’s autonomous navigation behavior in simulation.
  • Although the main object-recognition system, based on OpenCV, was led by another team member, this alternative implementation provided a reliable validation pathway and ensured system robustness under varying simulation conditions.

Technical Highlights

  • Framework: ROS2 Jazzy, Nav2, Gazebo
  • SLAM Module: slam_toolbox (online_async mode)
  • Hardware Abstraction: 2D laser scanner, simulated odometry (TF: map → odom → base_link)
  • Languages: Python, C++
  • Simulation Tools: Gazebo, RViz

Reflection

Through this project, I gained hands-on experience in ROS2-based navigation systems, SLAM algorithm tuning, and real-time system optimization.
The migration from 3D LiDAR to 2D laser SLAM deepened my understanding of computational efficiency trade-offs, while integrating Nav2 strengthened my grasp of robotic autonomy pipeline design—from localization to motion planning and control.

“Reliable autonomy begins with an efficient map — and every efficient map begins with robust SLAM.”
