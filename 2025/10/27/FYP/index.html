Final Year Project — “Chemical Imaging: Robotic Scanning Platform”

Supervisor: Dr. Simon Maher
Institution: University of Liverpool, Department of Electrical Engineering & Electronics

Overview

The Chemical Imaging: Robotic Scanning Platform was my final-year project, combining robotics, optics, and embedded systems to create a low-cost, portable, and modular spectrophotometer capable of performing automated surface scans for chemical imaging.

The system aimed to address the challenge of expensive and complex spectrophotometers that limit accessibility in healthcare diagnostics — especially in the context of remote medical applications and point-of-care testing.

The design built upon the open-source PySpectrometer2 framework, integrating a Raspberry Pi camera, diffraction grating spectroscope, and a stepper motor-driven linear platform to achieve one-dimensional chemical imaging.

System Design and Implementation

The complete system integrates three main subsystems:

  1. Optical Spectrometer

    • Designed with a grating-based optical path using dual 45° reflection prisms for compactness.
    • Operates in the visible light range (400–700 nm) with a parallel LED illumination source.
    • Uses a Raspberry Pi Camera (OV5647) to capture spectral data with real-time visualization.

  2. Linear Scanning Platform

    • Driven by a ball-screw mechanism actuated by a stepper motor (TB6600 driver).
    • Achieves positional accuracy of 0.00125 mm per step, allowing fine-resolution scanning.
    • Includes end-stop detection for safe homing and calibration.

  3. Software and User Interface

    • Entire system programmed in Python using PyQt5 for GUI development.
    • Features real-time spectral plotting, motor control, and automated scanning routines.
    • Implements a multi-threaded architecture for non-blocking motion and data acquisition.
    • Incorporates a dynamic RGB weighting algorithm for improved spectral accuracy.

Key Achievements

  • Successfully developed a functional robotic spectrophotometer capable of performing linear chemical imaging.
  • Validated system performance by comparing captured spectra against known light source references, achieving high consistency.
  • Designed a modular, 3D-printed mechanical structure allowing component replacement and future upgrades.
  • Implemented a custom motion-control and spectral analysis algorithm, integrating both robotics and signal processing principles.
  • Demonstrated strong feasibility for portable, low-cost diagnostic imaging applications.

Technical Summary

Component Specification
Processor Raspberry Pi 4 Model B
Sensor OV5647 CMOS (Raspberry Pi Camera)
Motion System Stepper motor + ball screw, 0.00125 mm resolution
Light Source Adjustable-intensity parallel white LED
Programming Python (PyQt5, OpenCV, NumPy)
Fabrication 3D printed PLA+ and laser-cut components
GUI Features Real-time plot, calibration, auto-scan, data export

Reflection

This project was a deeply interdisciplinary experience — combining mechanical design, control engineering, optics, and software integration.
It strengthened my ability to:

  • Translate research needs into technical specifications,
  • Design and test embedded systems for precision control, and
  • Integrate hardware and software into a cohesive robotic platform.

The system demonstrates how robotics and spectroscopy can be combined to create accessible diagnostic tools, aligning with future trends in portable healthcare and autonomous sensing.
